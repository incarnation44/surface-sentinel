7. 설계 차이/해석 메모
----------------------

- calculate_score의 "score = max(evidence) if valid else 0.0"은 최소 타당성
  (area_px >= min_area_px, mean_contrast_gray >= min_contrast_gray)을 통과한
  컴포넌트로 한정해 해석했다. 타당성 미달 소형 후보가 NG를 유발하지 않게 하기
  위해서다. decide_status도 같은 valid_components를 쓴다.
- timing_ms의 save_evidence 값은 오버레이/선택 단계 이미지 저장을 마친 뒤,
  결과 JSON 직렬화 직전에 측정한다. total은 10단계 값의 합이다. 따라서 결과
  JSON 자체의 직렬화/교체 시간은 total에 포함되지 않는 측정 관례를 쓴다.
- save_evidence는 T04 범위대로 단일 샘플 오버레이/결과 JSON만 쓴다.
  run.json/summary/원자 run 디렉터리는 T06 범위로 남겨두었다.
- ROI auto에서 distanceTransform은 ROI 마스크 밖을 0으로 두므로 ROI 경계
  픽셀의 border_distance_px가 1.0이 된다. ROI가 이미지 전체를 덮어 배경 0이
  없는 직접 단위 테스트에서는 distanceTransform이 최대 float 값을 반환한다.
