# ADR 0004 — 상태 문서는 자기 커밋 해시를 본문에 박지 않는다

- 상태: 확정 · 2026-11-10
- 맥락: PROJECT_STATUS·plan.md가 `HEAD 1db6c7b`로 적혀 있었지만 실제는
  `d6499aa`였고, 작업 트리는 clean인데 dirty로 적혀 있었다. 이후 작업에서
  잘못된 기준으로 저장소를 대조하게 됐다.
- 결정: 문서에는 **코드 최신 커밋 해시**를 적고, 그 위의 문서 커밋은 "문서 커밋
  (코드 변경 없음)"으로만 서술한다. 정확한 현재 값은 `git rev-parse HEAD`로
  확인하라고 안내한다.
- 대안: (a) 커밋 직후 해시를 문서에 박기 — amend나 후속 문서 커밋마다 다시
  어긋나 무한 루프가 된다. (b) 해시를 아예 빼기 — 회귀 추적 근거가 사라져 폐기.
- 근거: 한 작업 안에서 문서에 해시를 박은 뒤 amend가 필요해지자 값이 즉시 어긋났다
  (`ce96279` → `062088f`). 저장소 밖 문서는 순환 참조가 없으므로
  정확한 해시를 그대로 적는다.
- 결과: 문서 갱신 후에도 본문이 거짓이 되지 않는다. 갱신 담당자는 코드 해시만
  확인해 갱신하면 된다.
