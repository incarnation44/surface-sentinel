# ADR 0001 — T03 분할은 그룹 기반으로 하고 official_test 겹침은 보고만 한다

- 상태: 확정 · 2026-11-10 (T03에서 확정, 소급 기록)
- 맥락: KSDD2는 공식 train/test(2,331 / 1,004)와 이미지 단위 유사 중복이 함께 있다.
  이미지 단위 무작위 분할은 같은 결함을 tune과 test에 나눠 성능을 부풀린다.
- 결정: 정확 중복(sha256)과 dHash 거리 ≤2 근접 중복을 그룹으로 묶고, 시드 42로
  섞은 뒤 label 층화로 tune 60% / test 40%를 배정한다. `P_test >= 100`을 보장한다.
  official_test는 별도로 만들고, 내부 test와의 겹침은 보고만 한다.
- 대안: (a) 이미지 단위 무작위 — 누출 때문에 폐기. (b) official_test를 내부 test로
  대체 — 외부 분포 확인 수단이 사라져 폐기. (c) 겹침 제거 — 표본이 줄고 공식
  비교가 불가능해 폐기.
- 근거: L1–L4·L8 위반 0, tune 2,001건 / test 1,334건, 겹침은 L7로 보고
  (internal test 425, internal tune 579). `split_report.json`에 수치가 남아 있다.
- 결과: 겹침 표본은 임계값 튜닝·성능 측정에 **사용하지 않는다**. 튜닝 근거는
  tune만 쓴다. 이 제약은 T05에서도 그대로 적용한다.
