① 기준을 빡빡하게 잡으면 → 정상 오탐(False-NG) 폭발 멀쩡한 금속 무늬까지 불량으로 찍어 양품 폐기 · 생산 라인 중단
② 기준을 느슨하게 잡으면 → 불량 놓침(Escape) 증가 미세 흠집을 정상으로 통과시켜 출하 사고 · 고객 클레임 발생

Surface Sentinel 해법: 4-State 완충 설계
