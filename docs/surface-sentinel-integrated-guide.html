3. 문제 정의와 차별점 [DESIGN]

제조 표면 검사 파이프라인에서는 (1) 동일 부품·복사본 혼합에 의한 데이터 누출, (2) 처리 오류를 정상(OK)으로 삼키는 판정 혼선, (3) 분모·신뢰구간 없는 측정 왜곡이 반복된다.

  • 3-Class + ERROR 분리: OK NG REVIEW와 비판정 ERROR를 분리해 오류를 정상으로 오분류하지 않는다.
  • OK/NG 판정 불변 계약: 사람 검토와 에이전트 분석은 오직 REVIEW 샘플에만 부가되며, OK·NG 기계 판정은 절대 덮어쓰지 않는다.
  • 고정 규칙 엔진 채택 이유: 검사·감사·트리아지 전 과정에서 외부 모델 호출, 네트워크, 셸 실행을 배제해 오프라인 산업 환경에서 바이트 단위 결정론과 감사 추적성을 보장한다.

검사 판정은 고정 10단계 OpenCV 파이프라인이 단독 소유하며, 선택 E트랙(YOLO ONNX)과 2계층 에이전트는 engine_observations 및 agent_assessments로 분리 저장된다.

11. 10단계 검사 파이프라인 [DESIGN]

단계함수핵심 연산 및 실패 처리
1validate_input경로·split 확인(test/official_test는 E_SEALED_DENIED), 라벨 검증
2load_image바이트 SHA256 + cv2.imdecode, 최소 해상도(64×64)·표준편차(>=1.0) 검증
3prepare_roidark_floor=8 기반 부품 ROI 마스크 생성, 면적비 < 0.20 시 ROI_UNCERTAIN 플래그
4preprocess3×3 median + 배경 평활화(ratio 0.10, 21–61px), dark/bright 차분 및 MAD 기반 robust z-map + 품질 지표
5generate_candidates(z_map >= 7.6) & (response >= 16.0) & ROI 후 타원 open(3)·close(5)·merge(5)
6refine_mask재임계 + open(3) + 8-연결 요소 분해, area_px >= 40 필터 및 max_candidates=20 상한
7analyze_components후보별 bbox·면적·평균/최대 대비·주변 링 대비·ROI 경계 접촉(touches_roi_border) 계산
8calculate_score컴포넌트 증거 계산 및 최댓값(score)과 다중 후보 보정값 산출
9decide_status상태 진리표에 따라 OK / NG / REVIEW 및 사유 코드(ReasonCode) 결정
10save_evidence오버레이 PNG(2배 확대 선택) 및 SampleResult JSON 직렬화

13. 특징 추출 · 점수식 · 계측 눈금자 [DESIGN]

각 유효 컴포넌트의 증거 점수 evidence는 정규화 면적과 정규화 평균 대비의 기하평균에 포화 상한 1.5를 적용한다:

evidence = min( sqrt( min(area_px / 800.0, 1.5) * min(mean_contrast_gray / 22.0, 1.5) ), 1.5 )

ScoringConfig.ok_max는 F4 결정(ADR 0006)으로 제거됐으며, REVIEW_BAND_MAX = 0.40이 코드 상수로 동결됐다. 유효 컴포넌트가 1개라도 존재하고 score가 0.50 미만이면 경계/다중후보 규칙에 따라 REVIEW로 격리된다.

16. 지표 정의와 분모 · 신뢰구간 규칙 [DESIGN]

모든 비율 지표는 반드시 numerator(분자), denominator(분모), ci95_low/ci95_high(Wilson 95% CI)와 함께 기록한다. ERROR 행은 판정이 아니므로 분모에서 제외한다.

  • defect_escape_rate = OK_on_defect / P (목표: 점추정 ≤ 15%, Wilson 상한 ≤ 20%)
  • good_false_ng_rate = NG_on_good / N (목표: ≤ 20%)
  • review_rate = (REVIEW_defect + REVIEW_good) / T (목표: ≤ 40%)
  • localization_recall_iou0.10 = matched_GT(IoU >= 0.10) / 전체 GT (목표: ≥ 50%)
  • 그룹 부트스트랩(F6): b=2000, seed=20261111, alpha=0.05 이미지/그룹 단위 복원추출

26. 알려진 한계와 미입증 사항 [NOT_MEASURED]

  • 봉인 test escape Wilson 상한 미달: 점추정 14.79%이나 상한이 21.55%(> 20%)로 FAIL이다.
  • 생산 유병률 보정 및 현장 일반화: KolektorSDD2 표본 유병률(~10.7%) 기반 측정이며 실제 양산 라인 유병률 보정·현장 일반화는 [NOT_MEASURED] 상태다.
  • 면적 병목 구조: REVIEW의 95.12%가 133px 이하 면적 병목에 속하며, T09 교정 프로파일은 120장 부분집합에서 발동 0건으로 고정 모드 유지가 확정됐다.
  • 가장자리 15% 편중: NG 후보 43.67%·REVIEW 후보 45.86%가 스트립 좌·우 경계에 집중돼 조명/가장자리 ROI 정밀 점검이 필요하다.

28. 핵심 용어 사전 [DESIGN]

용어정의
escape실제 결함(defect) 이미지를 OK로 오판한 비율(분모 = 결함 이미지 수 P)
false-NG정상(good) 이미지를 NG로 과잉 판정한 비율(분모 = 정상 이미지 수 N)
observe-only기계 판정(OK/NG/REVIEW)과 동결 설정을 절대 변경하지 않고 별도 기록·정렬·감시만 수행하는 원칙
Pivotal 후보해당 후보 하나만 제거(Leave-One-Out)해도 이미지 판정 등급(NG→REVIEW/OK)이 바뀌는 결정적 후보
PSIPopulation Stability Index — 분포 이탈 지표(<0.10 정상, 0.10–0.25 주의, >=0.25 드리프트 경보)
